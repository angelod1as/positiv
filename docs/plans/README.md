# Implementation Plans

This directory contains temporary implementation plans for Linear tasks.

## Purpose

Plans are generated by the worktree-management skill to guide implementation:
- PRD (Product Requirements Document)
- Implementation strategy
- TDD baby steps
- Testing checklist

## Lifecycle

1. **Creation**: Generated when running "Plan POS-XXX"
2. **Usage**: Reference during implementation
3. **Deletion**: MUST be deleted before PR creation

## Naming Convention

Format: `POS-{number}-{slug}.md`

Examples:
- `POS-314-email-transacional.md`
- `POS-357-auto-lists.md`

## Important Notes

⚠️ **Plans are temporary** - Delete before creating PR
⚠️ **Not for long-term docs** - Use `/docs/` for permanent documentation
✓ **Tracked in git** - But meant to be short-lived
